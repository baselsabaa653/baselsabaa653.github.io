Mobile Application Penetration Testing

Basel Sabaa | Mobile Security Notes

What is Mobile Pentesting?

Mobile penetration testing is the process of testing Android and iOS applications for security vulnerabilities.

Android Application Structure

An Android APK may contain:

  • AndroidManifest.xml
  • classes.dex
  • resources.arsc
  • res/
  • lib/

Common Tools

  • ADB
  • JADX
  • APKTool
  • Burp Suite
  • Frida

Basic ADB Command

adb devices

Displays Android devices connected to the computer.
